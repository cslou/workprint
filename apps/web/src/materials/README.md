# Saved material reads

Production rendering reads only the exported, versioned saved-content shapes. Script action/dialogue order is preserved; a reference without media remains visible with the approved No image treatment and a text-only sheet. Missing fields are not inferred from opaque JSON or identifiers. Viewing content, history or Library never grants approval or sends a write.

Version history and Library share the framework-free bounded page reader in `@workprint/api-client`, with feature-owned React bindings and styling. Requests are manual beyond the first page. Scope/resource/filter changes create a fresh reader synchronously and dispose the previous reader; late completions cannot repopulate the new scope. Errors preserve loaded rows and the same cursor for an explicit retry. Duplicate IDs/cursors and pages over 100 items fail closed; a view retains at most 1,000 loaded items. Terminal pagination keeps its control until layout settlement moves focus to the first newly added item, without stealing focus from another active control.

Workspace uses pin exact versions independently of Library's latest version. History may include newer unadopted versions as well as earlier ones; those versions stay read-only. The known N earlier caption is shown only when every displayed alternative actually predates the workspace version and the final page is loaded.

Legacy labelled display/history prerequisites remain only for consumers whose producers belong to later phases. They are not production saved-work data. Existing flat-field editor fixtures retain their unavailable Save behavior; structured Script editing and successful saves belong to the next story. The saved-work test mount composes the real Shell and client without display overrides, because ordinary sign-in/conversation entry depends on the unintegrated parallel sprint. It does not replace that entry flow or add a producer/seed route. Visual comparisons also mount the real MaterialPanel read composition in inert approved framing, without substituting workspace/version results or component CSS. Frozen local approved read proposals under `outputs/verification/sprint-005/design-proposals/owned-reads/` are required visual prerequisites; missing references fail, never skip or regenerate from application output. The browser and backend exposure checks exclude these test compositions from production.
