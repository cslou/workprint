# Exact Library reuse

Library kind filters call the supported bounded `library` read. Search is local to loaded validated names, and is labelled as such. Script locations and reference subjects supply names through the closed saved-content schemas; unsupported content falls back to a kind/version label, never an opaque JSON property or ID. Library tiles carry no conversation-specific Draft/Ready state. No Examples switch or production catalog is installed.

Select only updates the scope-owned tray. Inspect opens exact read-only content and bounded history; neither grants approval. Private images use authenticated access acquisition followed by credential-free object reads. Existing saved videos play and download through the shared `media/` `PrivateClip`, which uses the same owned exact-version media access; playing or downloading never uses or chooses the version, and this does not qualify video uploads. Missing/inherited reference coverage remains undeclared.

Explicit Use captures the exact version, current conversation, purpose and optional reference role. Script and Storyboard use their own purposes; image/video/reference inspection uses reference purpose only. The shared immutable command controller locks unknown payloads and reconciles only on explicit Retry. Closing stops observation, not a committed use. The scope retains exact inspection/role/command identities across Back/Close/Escape, while React Aria returns invoking focus. Scope teardown disposes controllers and prevents late callbacks.

Multi-attach captures exact choices and submits sequentially. Known successes leave the pending tray and are never replayed. An uncertain choice retains its operation ID and full original payload before any unsent choices continue. Selected full-version receipts and display facts share a 4 MiB/1,000-choice bound; direct command and compact inspection/role indexes each retain at most 1,000 entries. Unresolved direct commands are not evicted to admit new mutations.

Shell composes the Library with receipt-only workspace updates. It never invalidates/reloads the entire projection after reuse. Existing manual editors remain mounted with original input/base/recovery identity while reuse receipts wait for editing to finish. In particular, acknowledging an earlier unknown save cannot locally reapply that save's old use over a later explicit reuse receipt. Real persisted command replay is checked independently by the browser/backend tests.

The test-only `library-media-work.ts` owns its Postgres/emulator/sandbox resources. Image fixtures pass the real verifier. Saved-video prerequisites are trusted synthetic generated media, fully decoded/probed and given a generated poster before isolated setup installs them; they do not call product video authorization/confirmation or qualify the deferred MP4 parser. No fixture producer, catalog seed or test route is exported by production.
