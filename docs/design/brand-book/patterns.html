Accessibility

Proposed target WCAG 2.2 AA. All text colours pass. The chat-box outline does not, and you chose to keep it as a recorded gap. Full table and required behaviour in design.md.

The new Editor reference uses the existing subtle-text colour for a stronger composer outline; it does not carry the legacy faint-outline exception into this surface. Native layout controls are checked separately from editing gestures, modal behaviour and full assistive-technology coverage, which remain incomplete.

The new material controls use no focus rings. Keyboard focus is indicated by a 2px label underline with 2px offset in the existing text color; normal mouse appearance stays clean. This scoped change does not remove focus indication from other controls or certify complete accessibility.
