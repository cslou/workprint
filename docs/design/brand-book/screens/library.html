Library reuse

ProvisionalProvisionally approved under Lou’s delegation; pending Lou’s Phase 3 ratification.

Kind filters, separate Select and Inspect, and an exact-choice tray. Inspecting never approves; Use pins the exact version and role in this conversation only, without choosing a Shot video. Unconfirmed uses and partial attachments retry the original choice, never replaying known successes. Reference edits save through manual save and keep unsaved text on conflict. Search covers loaded names only. Each frame is one viewport; at narrow widths the Library grid scrolls inside the dialog. State rules.
