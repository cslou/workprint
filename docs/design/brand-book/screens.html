Flow 1: Create a video

A new user, with nothing saved yet, goes from a description to a chosen video version, not automatically a finished film. 9 steps; open any step for the full screen.

  2. 2Describe and break downThe agent drafts the script, explains the next steps and asks questions
  3. 3Characters and placesFor each asset: upload photos, describe it, or have it designed
  4. 4Choose Vale's lookThe agent makes three looks; pick one or suggest changes

Flow 2: Create a scene

A new user, with nothing saved yet, asks for a short scene of three shots. 10 generation/review steps, then the Editor continuation; open any step for the full screen.

  1. 1Opening screenThe agent asks what you'd like to make
  2. 2Describe the sceneThe agent drafts the script with a shot breakdown, and asks questions
  3. 3Characters, places and propsFor each: upload photos, describe it, or have it designed
  4. 4Choose the looksThree looks for each described item; pick one
  5. 5Approve the reference sheetsAll sheets together
  6. 6Plan the storyboardPanels and camera per shot, in one approval
  7. 7Approve the storyboardCheck the panels; edit in the board and regenerate
  8. 8Make the videosOne video per shot, in one approval
  9. 9Choose the takesPlay the scene in order; choose or redo a shot
  10. 10Compare versionsA new version of shot 2; watch both in the scene and choose

Roadmap: Project workspace Partial

A separate future-roadmap reference—not an approved flow or part of the demo. Explore Project and Scene conversations, browse material, then open a complete Scene edit. This addition does not change Flow 1, Flow 2 or the existing Editor continuation, and makes no delivery commitment.

Open the standalone flow → · Agent reference and boundaries. The example uses the existing Vale/Mercer Scene: one complete Script, four Assets, three Shots, four Panels and a 13.4-second snapshot. No new story or media.

  1. 1Browse the ProjectProject conversation and material; the Scene list expands independently
  2. 2Focus the materialChoose Storyboard and a Scene filter without switching conversations
  3. 3Enter the Scene conversationSelect the Scene in the sidebar, then Videos; the filter disappears
  4. 4Open the Scene EditorEditor → opens all three Shots, not an isolated Shot or a Project film
  5. 5Return to VideosThis copy resets to Project/Videos; context restoration is not demonstrated

Cards show captured states; use the standalone flow to try tabs, filtering, sidebar selection and disclosures. State rules: Project · filter · Scene · Editor · return.

Keep the two controls distinct: sidebar selection changes the conversation; material tabs and the dropdown do not. The panel retains its 380px/330px widths and stacked narrow layout. The divider stays below the tabs, not below the dropdown; the Project dropdown-to-material gap is 16px. Material keyboard cues use the existing 2px underline with 2px offset, not rings.

Working reference mechanics: navigation, tabs, filtering, reset, disclosures, Compact timeline and scrolling. Playback, generation, editing, Send, Undo, persistence and export processing do not work. Seven tracks are illustrative; separate dialogue/ambience are assumptions. Direct Export remains valid without an Editor visit, despite its disabled control here.

Still unresolved: Project membership/order, shared-Asset ownership, multi-Scene composition and linked updates, conversation routing/restoration, real editing/recovery and completed export. Both Project and Scene entries open the same one-Scene Editor; that is not evidence of Project-conversation continuity or film-level editing. Missing/loading/error/validation/success states and broader accessibility remain unfinished.

Versionable reference HTML/CSS lives under docs/design/roadmap/project-workspace/. Existing media and screenshots remain local, git-ignored and not licensed for redistribution; the reference is not self-contained without those images. The separate three-Scene exploration is preserved unchanged, not connected to this Scene Editor.
