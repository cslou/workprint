05

Color

A warm cream light theme with one blue for actions and a tan for things that are done. Components use the semantic tokens below; the primitive palette only feeds them. Alpha colours are shown over --color-bg-canvas.

Semantic colors

Backgrounds

--color-bg-canvas#faf8f3Page background and inner wells.
--color-bg-sunken#f7f5edSidebar, user messages, image wells.
--color-bg-surface#fffefaRight panel, chat box, cards, viewers.
--color-bg-paper#fcfcf9Reference-sheet page.
--color-bg-hover#0000000aHover fill; neutral (Empty) status fill.
--color-bg-selected#125da31aSelected or draft fill: Draft status, flags, changed chip.

Layout and controls

The existing foundation values are unchanged. The dedicated Editor layout records its new reference geometry separately; this integration does not adopt a new application token file.
