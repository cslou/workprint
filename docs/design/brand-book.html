Overview

Workprint is the chat-first app for making one video or one scene. In scope: Flow 1, Flow 2, the demo, the library picker, and the Editor entry and layout. The material-control additions are recorded separately. Detailed editing and export completion remain partial; multi-scene editing is deferred. Still incomplete: logo, Studio, dark theme, and failure, error and cost states. The name is Workprint. Exact values and rules are in design.md, the source of truth.

Future roadmap: Project workspace → Scene Editor is a separate exploratory flow, retained for future planning. It does not change the approved flows, existing Editor continuation or demo, and is not an implementation or delivery commitment.
